# GRID 外部参考零样本音色控制诊断（2026-10-15）

## 结论与范围

当前生成确实明显保留目标 GRID 说话人的身份，但外部参考条件并未完全失效。显式 CAM++ 向量可以因果性地改变生成音色；当前的控制程度不足以压过视频关联的已见 GRID 声音。直接拼接参考文本没有解决问题，并使两个权重的目标内容 WER 变差。VAE 能重建外部参考音色，未发现 GT 音频误入生成条件的路径。

前一轮全量 3,274 条、150k EMA 的 WavLM SPKSIM_GT/REF 为 **0.51334/0.13604**，3,192/3,274 条（97.49542%）及全部 33 个分组的均值均 GT > REF。本诊断沿用其冻结配对，对清单中每位 GRID 说话人的第一条目标做配对干预，共 **33 条、33 组参考**，同时验证 EMA 100k 和 150k。选择规则不看指标；它是固定 seed 的平衡诊断子集，不是新的全量基准，也不是随机总体估计。

参考来自 33 个不同 CelebV-Dub 视频；没有据此宣称完成跨所有预训练语料的人员身份去重。

## 受控实验与可复现性

- 每个权重 8 组 × 33 条：复用已校验的基线 33 条、新生成 231 条。另各重生成 3 条基线，六条 WAV 均与上轮全量输出逐字节一致。
- 仅改变列明条件；P/T、目标裁剪、seed=0、Euler/EPSS、32 NFE、sway=-1、CFG text/video=5/2、FP32/high、EMA、decoder 保持一致。所有新干预逐目标的初始目标噪声 SHA256 一致。
- 拼接文本使用历史 `reference_target_text` 分隔规则；全部样本满足长度界限，不增加采样时长。关闭视频使用训练中的 learned null，即 `ignore_modality='video'`，不是给原始视频填零，也不是仅设置 video CFG=0。
- CAM-only 交换使用按 GRID speaker ID 字典序循环的另一条外部 REF 向量；原声学 prompt 保持不变，故这是有意冲突两种参考的单变量实验，不代表完整替换参考音频。
- 两套说话人编码器分别评分：独立 WavLM-Large/ECAPA 与条件提取所用 CAM++。只能比较同一编码器内部的对照，不能横向解释两套余弦绝对值。
- WER 沿用 Whisper Large-v3、FP16、English、beam=5；每条 raw hypothesis 同时计算原始、数字展开、数字展开并去 sp/sil 三种协议。表中主 WER 为第三种 corpus WER，每组 198 个参考词，不平均逐句 WER。
- 额外 66 条 GRID 音频（每人两条其他句子，排除选中目标）构造 33 个说话人质心，检验同人异文本身份；33 个原始外部 REF、canonical REF 及 VAE 重建用于参考/codec 控制。

## 显式 CAM++ 到底有没有作用

150k 只清零 CAM++，保留原声学 prompt：WavLM 对原 REF 从 **0.13291 降至 0.01649**，CAM++ 对原 REF 从 **0.28703 降至 0.05238**；33/33 条的 CAM++ REF 分数都下降。显式向量并非未接线或被完全忽略。

只交换 CAM++、其余保持不变：

| 对比对象 | 编码器 | 交换前 | 交换后 | 上升条数 |
|---|---|---:|---:|---:|
| 新 CAM++ 来源的 REF | 独立 WavLM | 0.00327 | 0.08649 | 28/33 |
| 新 CAM++ 来源的 REF | CAM++ | 0.00570 | 0.22841 | 33/33 |

与此同时，对原 REF 的 CAM++ 相似度由 0.28703 降至 0.05755，33/33 条均下降。这验证了音色会朝新条件移动，但交换后仍明显保留目标 GRID 身份。

基线在仅含 33 条外部参考的候选集合中，原 REF top-1 为 WavLM 9/33、CAM++ 26/33。GT 不在这个参考候选集合中，因此 **26/33 不能解读成克隆成功率**。它仅补充说明外部参考信息进入了生成。

## 为什么更接近 GT：视频关联的身份占主导

为排除生成与 GT 说了相同文字造成的全部解释，每位 GRID 说话人用两条其他句子的 GT 音频构造质心。选中目标的真实 GT 在两个编码器下均能正确检索所属说话人 33/33，控制本身有效。

| 150k 条件 | 正确 GRID 身份 top-1 /33：WavLM | 正确 GRID 身份 top-1 /33：CAM++ |
|---|---:|---:|
| 原配置 | 29 | 28 |
| 关闭声学 latent 和 CAM++ | 33 | 33 |
| 关闭视频 | 2 | 3 |

原配置相对同人异文本质心的 WavLM 相似度为 **0.43530**，关闭视频后为 **0.11913**。关闭两种参考后，生成与 GT 的 WavLM 相似度上升到 **0.74520**，仍能从 33 个说话人中全部检索到正确的 GRID 身份。

这些结果强烈支持模型利用视频条件恢复训练中已见 GRID 说话人的声音。它们尚未分离视觉外观、发音习惯、韵律或质量变化的具体贡献，不能声称已定位到某个视觉特征维度。

关闭视频不是可用修复：150k WavLM REF 仅从 0.13291 到 0.15416，CAM++ REF 从 0.28703 到 0.28074，WER 却从 **15.65657% 升至 69.19192%**。

## 训练机制与输入分布：已核实事实和待验证因素

1. **训练身份与条件高度相关。** GRID train 29,531 条和 val 3,274 条包含相同 33 位说话人。训练 latent、视频、完整文本、完整波形 CAM++ 均来自同一句音频，没有“目标人物身份与参考身份不同”的配音监督。模型可通过视频关联的身份降低监督损失，不必学会在冲突时优先跟随 REF。
2. **新增 speaker 分支只在 GRID 上学到映射。** S2c parent 迁移时新增 `speaker_proj.weight` 为零初始化；100k/150k EMA 已非零，Frobenius 范数 20.07930/23.51416，矩阵满秩 192。33 个外部参考经投影后仍不同、非零，排除投影整体坍缩。它只注入 18 层中的最后 6 层。新参考映射的泛化、注入位置是否限制控制力，需要另外训练消融，不能仅凭层数认定原因。
3. **没有显式身份一致性损失。** 当前目标是 flow MSE + CTC + WavLM REPA；传入 speaker embedding 本身不会构成“生成声音必须等于该身份”的硬约束。
4. **prompt 长度改变。** GRID 训练片段为 2.975–3.000 秒，随机隐藏 70–100%，可见同句音频名义最大约 0.9 秒。外部 prompt 为 1.2–4.175 秒（latent 网格）、中位数 2.925 秒，全部更长；P+T 为 4.2–7.175 秒。该分布差异可能影响泛化，但本次没有独立做长度扫描，不能把它列为已证实主因。
5. **文本不是严格按目标区隔离。** 当前 C2 `prompt_isolated_ca=False`，前 12 层全局文本 cross-attention 可更新参考区；训练文本覆盖完整同句。历史外部参考入口以及[上游 F5-TTS 官方推理](https://github.com/SWivid/F5-TTS/blob/main/src/f5_tts/infer/utils_infer.py)会拼接参考与目标文本。因此漏参考文本值得检验，但“应该拼接”不能替代当前权重的实测。
6. **直接拼接又引入更长文本。** GRID 训练始终 6 词、20–31 字符；本次拼接后 36–117 字符，且包含开放词汇。150k 拼接后 REF 仅 +0.00301（WavLM）/+0.00731（CAM++），主 WER 从 31/198 增到 70/198；100k REF 反而下降。只能得出当前权重直接拼接不能解决问题，不能推导所有声学 prompt 模型都不需要参考文本。
7. **CFG 不是独立 speaker 旋钮。** 当前 5/2 配置的采样向量场为 `3*full + 3*TTS - 5*null`，TTS 同时保留文本、prompt 和 CAM++。speaker/prompt dropout 在训练中耦合；直接提高 text CFG 同时改变多路条件。`get_speaker_delta` 先 L2 归一化，所以直接把缓存 CAM++ 向量乘大不会增强条件。

源码锚点：`semantic_vae_dataset.py:433`、`grid_dataset.py:337`、`cfm_vt.py:310`（mask）、`:341`（dropout）、`:390`（损失）、`dit_vt_mm.py:349`（全局文本 CA）、`:620`（speaker 归一化/投影）、`:920`（末六层注入）。完整证据见运行目录 `conditioning_audit.json`。

## 排除的实现问题与评测偏差

- 推理读取实际冻结 REF 的 VAE latent 与 CAM++，不读取目标 GT 音频、目标 latent 或目标 speaker cache；只解码 `[P:P+T]`。
- 33 条 REF 的 CAM++ 均为不同的有效单位向量。使用相同权重重新提取 canonical REF 并与实际条件缓存逐条核对，归一化后逐元素最大绝对差为 0。
- **生成的视觉缓存是 video-only。** `prepare_grid.py:459` 调用 `extract_finetune(source={"audio": None, "video": video}, ...)`。冻结提取实现的 7 个哈希与当前源码一致；33/33 个真实 `video_40hz` 缓存的哈希、shape、stage receipt 和提取指纹一致。联合音视频特征仅存在于评测 `avhubert_joint/{gen,gt}`，与生成缓存文件及内容均不同。本项为源码/冻结来源/缓存审计，没有声称重新提取 AV-HuBERT。
- VAE 直接解码 33 个原始参考 latent，相对原 REF 的相似度为 **WavLM 0.92465、CAM++ 0.89028**，两个编码器均能检索回自身参考 33/33。说明 codec 能保留这些外部音色；不等于生成模型产生的 latent 已正确保留身份，也不是完美重建的保证。
- 原始与 canonical REF 的最小余弦为 WavLM **0.99993**、CAM++ **0.99878**，声道平均、重采样及 PCM16 差异不能解释大幅 GT/REF 差距。
- 33 条目标 GT 对其外部 REF 的均值仅为 WavLM **0.00599**、CAM++ **0.01210**。生成相对 REF 已明显高于该控制，不能把 0.13 余弦直接当成“完全没有参考信息”。
- 新的 WavLM 基线评分逐条复现原全量相应样本，100k/150k 最大绝对误差为 7.802e-8/7.680e-8。所有样本/输入绑定、嵌入缓存哈希、两套评分覆盖、WER 编辑计数与初始噪声已独立复算。

## 后续修正方向（尚未训练验证）

优先修正训练任务与身份泛化，再考虑推理超参数。

- 训练中使用同说话人、不同句子的独立参考音频，并按实际推理方式组织参考文本、目标文本、P/T 和可见区域；覆盖实际参考长度。仅同身份换句仍不能完全打破视频身份关联。
- 对新 CAM++ 分支做更丰富说话人的训练/预训练，采用身份分离的验证，并保留外部参考跟随测试；检查 GRID 微调是否损失原有跨域参考能力。
- 明确约束生成身份跟随参考，同时限制视频带入身份。可研究独立的 speaker guidance/投影后强度、视频身份不变表示、独立参考训练和 speaker consistency 目标；需要兼顾 WER、音画同步和独立 WavLM 评测，不把提高 CAM++ 自评分当唯一成功标准。
- **不要随机更换训练 REF，却仍以原人物 GT 音色为唯一监督。** 这会继续奖励忽略 REF；跨身份条件需要与期望声音相符的目标或适当的一致性训练设计。

当前证据不支持直接把“拼接参考文本”或“关闭视频”作为默认修复。本次没有改模型权重、训练目标或原全量推理结果。
